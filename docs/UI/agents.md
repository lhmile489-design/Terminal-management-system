有一条新规则：文字颜色不允许再加透明度，比如 `text-ink-faint/50`。上次探针测到的 1.99:1、2.26:1 都是这种写法造成的。需要更弱的层级就单独定义一档颜色，并且这一档本身要过 4.5:1。

### 字体

- 标题、数字、品牌：Manrope，以 woff2 格式打包进应用，只带 600/700/800 三个字重。统计数字用等宽数字（`tabular-nums`），刷新时不会左右跳动。
- 正文：Segoe UI Variable + Microsoft YaHei UI，保持不变。Manrope 没有中文字形，中文本来就会回落到雅黑。模板里的 Inter 不用，`CLAUDE.md` 原本也禁用它。
- 等宽：Cascadia Code，用于端口、路径、终端。
- 字号下限：正文 13px，辅助标注 12px。不再出现 11px 以下的文字，上次探针在工作台测到 28 处。

### 形状与层次

- 圆角分三档：卡片 16px，控件 10px，胶囊和标签 999px。大容器不用全圆角，这条保留。
- 阴影分三档：
  - 静态卡片：`0 4px 14px / 0.07`
  - 悬停：`0 8px 22px / 0.12`
  - 浮层：`0 16px 40px / 0.16`
- 深色主题不用阴影表现层次，靠表面颜色逐级变亮，再加 1px 描边。
- 渐变只允许用在品牌标识这一处，其他地方一律纯色。
