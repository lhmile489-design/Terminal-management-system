# Mile Terminal UI/UX 与布局重构方案

> 文档版本：2026-10-27（交互方案定稿）
> 适用范围：`mile-terminal-management/src/renderer/`（渲染层），少量主进程默认值
> 风格参考：`E:/WebApp/Claude Fable 5 Max/style-templates/pages/39-bento-box-grid.html`（便当盒网格）
> 前序讨论：`docs/UI/agents.md`；决策逐条见第 8 节
> 静态原型：`docs/UI/prototype/index.html`（双击用浏览器打开，无网络依赖，只演示交互与版式，不接真实数据）

## 1. 目标与边界

目标：不只换配色，而是重做整个应用的信息架构、布局骨架、交互方式和反馈。风格参考模板的便当盒网格：不等大的模块化磁贴、中性浅底、柔和阴影、清楚的数字层级。

交互核心是「以服务为中心」：任何地方点一个服务或任务，都打开同一个详情分栏，启停、看输出、诊断、改配置、构建都在里面完成，不再跳页面。

保留：
- 深色 / 浅色 / 跟随系统 三种主题切换（`useTheme` + 主进程 `nativeTheme`，`<html data-theme>` 驱动）。先打磨浅色，深色保持可用、后续微调（Q16）。
- 所有现有功能、IPC 接口和安全红线。本次只动渲染层的组织、展示与交互，不改任何特权逻辑。
- Phosphor 图标、无 emoji、不做顶部视图切换器。

不做：
- 不引入组件库（shadcn、MUI 等）和单元测试框架。
- 不照搬模板的营销页元素：大标题 hero、全圆角大按钮、`scale(1.02)` 悬停。

## 3. 信息架构与布局

### 3.1 整体结构

│ NavRail  │ ViewHeader：标题 + 一行说明 + 本页主操作                  │
│ 184/56px │───────────────────────────────────────────────────────│
│          │ 内容区：padding 24px                                    │
│ 服务     │   服务页：工作组磁贴 2 列 ⇄ 列表 360px + 详情分栏          │
│ 总览     │   总览页：4 列便当网格                                    │
│ 终端     │   终端页：会话列表 240px + 终端铺满                        │
│ ─────    │                                                       │

│ 关于     │                                                       │

最小窗口 1180px、导航展开时：内容区约 948px。

### 3.2 外框

- 标题栏 40px：左侧品牌标识（全应用唯一允许渐变处）；中间搜索框，点击或 `Ctrl+K` 打开命令面板；右侧「动态」按钮（未读数，失败事件让角标变错误色）、窗口控件。毛玻璃 `blur(14px)` + 85% 画布色。可交互元素全部 `no-drag`。
- 导航轨：带文字标签，展开 184px / 折叠 56px，折叠状态存 `localStorage`。选中项品牌蓝浅底 + 左侧 3px 指示条滑动。折叠时图标按钮保留 `aria-label` 和悬停提示。
- 导航 5 项（Q19）：

| 位置 | 项目 | 快捷键 | 来源 |
| :--- | :--- | :--- | :--- |
| 上 | 服务（默认首页） | `Ctrl+1` | 前端启动台 + 后端控制台 + 工作组 |
| 上 | 总览 | `Ctrl+2` | 工作台，功能全部保留 |
| 上 | 终端 | `Ctrl+3` | 终端页 + 日志页 |
| 下 | 设置 | `Ctrl+4` | |
| 下 | 关于 | `Ctrl+5` | |

- 实时动态：360px 覆盖式抽屉，右侧滑入、遮罩淡入、毛玻璃；`Esc` 关闭，打开时焦点进抽屉，关闭后还给按钮。
- 视图头：标题（Manrope 700，22px）+ 一行说明（13px 次要文字）+ 右侧主操作。去掉 eyebrow 和罗马字副标。随内容滚动，不吸顶。

### 3.3 服务页（Q10、Q12、Q20）

视图头主操作：「添加服务」「新建工作组」。

工具条：左侧「全部 / 前端 / 后端 / 任务」分段切换，右侧搜索（名称、端口、路径）。搜索时无命中的工作组段整段隐藏；类型切换只过滤段内成员。

工作组磁贴：
- 头部：组名、环境标记（dev / sandbox / prod）、「N/M 运行中」、「全部启动 / 全部停止」、「⋯」菜单（编辑、改环境、添加服务到本组、删除工作组）。
- 描边随组状态：有成员出错 → 错误色；全部运行 → 成功色；其余默认。底色不变。
- 成员行 44px：状态点、框架图标、名称、端口（等宽）、启停按钮（图标 + 文字）、「⋯」菜单（重启、打开目录、查看产物、用 HBuilderX 打开、移除）。
- 一个服务属于多个组时在每组下各出现一次。末尾「未分组」段，无环境标记和整组启停。

两种状态：
- 未打开详情：磁贴 2 列网格。
- 打开详情：磁贴 1 列叠放在左侧约 360px 列表，右侧详情约 570px。分栏可拖宽并记住宽度；「最大化」让详情铺满内容区，`Esc` 回到分栏。
- 选中行左侧 3px 品牌蓝指示条，切换时滑动。

详情面板：
- 头部：框架图标、名称、状态胶囊、端口；按钮：启停（主按钮）、最大化、关闭。
- 标签：

| 标签 | 内容 | 来源 |
| :--- | :--- | :--- |
| 概览 | 运行时长、PID、CPU / 内存小曲线、所属工作组、项目路径（可复制）、最近一次退出原因 | 新 |
| 输出 | 该服务的终端会话；停止后保留上次输出，新一次运行前加分隔线 | `LaunchpadTerminalPanel`、后端输出区、工作组终端预览 |
| 诊断 | 预检逐项结果 + 「修复」；端口被占时显示占用进程 | `PrecheckPanel`、诊断页 |
| 构建 | 仅 Java 项目：Maven / Gradle 目标、打包 | 后端控制台 |
| 配置 | 直接编辑：常用 / 高级分组，底部保存 / 放弃条（Q13） | `EditEntryDialog` |

- 默认标签：记住上次用的标签；新选的服务没有该标签（如非 Java 没有「构建」）时回到「概览」。失败通知条的「查看输出」总是打开「输出」，诊断提示总是打开「诊断」。
- 任务类条目：主按钮为「运行」+ 脚本下拉；概览显示最近几次运行结果。
- 仅登记条目：无启停按钮，头部显示「仅登记」，诊断标签说明原因。
- prod 环境的组成员启动前弹确认（Q14）。
- 配置有未保存改动时，切换服务、关闭面板、切换导航都先提醒。

### 3.4 总览页（Q11）

4 列便当网格，`grid-auto-rows: minmax(140px, auto)`，gap 16px。现有区块全部保留：

| 行 | 磁贴 | 跨度 |
| :--- | :--- | :--- |
| 1 | 统计数字（每个一块，大数字 Manrope + `tabular-nums`，附小曲线或说明） | 各 1 列，超过 4 个换行 |
| 2 | 服务操作台（运行中与常用服务的快速启停） | `span-2 row-2` |
| 2 | 新发现的端口（可「提升为我的服务」，提升后跳服务页并打开新条目详情） | `span-2` |
| 3 | 我的服务端口表 | 整行 |
| 4 | 应用后台（默认折叠） | 整行 |
| 5 | 受关注进程 | 整行 |

在总览点一个服务：跳到服务页并打开它的详情（Q19）。

### 3.5 终端页（Q18）

- 顶部「终端 / 全部输出」两个标签。
- 「终端」：左侧约 240px 会话列表，分「我的终端」（自建 PowerShell，带「+ 新建」）和「服务会话」（按工作组归类，状态点区分运行中 / 已退出）；右侧终端铺满，不用网格、不留内边距。
- 「全部输出」：原日志页。筛选条（级别、会话、关键字）+ 日志流填满剩余高度；点一条日志跳到对应会话。

### 3.6 设置与关于

- 设置：2 列网格，每个分组（采集、外观、终端、退出、通知、快捷键一览入口）一块磁贴。开关、步进器点击区域 ≥ 24px。
- 关于：品牌磁贴 `span-2 row-2`（唯一渐变处之一，与标题栏品牌同源）+ 版本、教程、项目介绍磁贴。

### 3.7 对话框与命令面板

- 统一 `DialogShell`：16px 圆角、浮层阴影、遮罩淡入、焦点陷阱、`Esc` 关闭。
- 添加服务：分步（选目录 → 识别 → 确认）；完成后自动打开新条目详情；从工作组菜单发起时直接归入该组。
- 端口、脚本选择对话框换外壳，内部表单 2 列。
- 命令面板：能搜服务、工作组、页面，并对服务直接执行启动、停止、重启、打开详情、打开目录。

## 4. 视觉系统「已定」

### 4.1 色彩

浅色为主。对比度按 WCAG 公式手算，实现阶段用 harness 实测核对。

| 用途 | 浅色 | 深色 | 文字对比度（卡片上） |
| :--- | :--- | :--- | :--- |
| 画布 | `#F6F7FB` | `#0F1219` | |
| 面板与卡片 | `#FFFFFF` | `#151A23` / `#1B212C` | |
| 主文字 | `#1B1F2E` | `#E4E8F0` | 约 16:1 / 14:1 |
| 次要文字 | `#4C5265` | `#A3ACBC` | 约 7.8:1 / 8:1 |
| 最弱文字（标签、单位） | `#5F6678` | `#8A94A6` | 约 5.7:1 / 5.3:1 |
| 品牌蓝（主按钮底） | `#2563EB` | `#2563EB` | 白字约 5.2:1 |
| 品牌蓝（文字用） | `#2563EB` | `#7AA7FF` | 约 5.2:1 / 6.8:1 |
| 成功 / 警告 / 错误文字 | `#15803D` / `#92400E` / `#B91C1C` | 提亮一档 | 都 ≥ 5:1 |
| 成功 / 警告 / 错误浅底 | `#DCFCE7` / `#FEF3C7` / `#FEE2E2` | 15% 透明叠加 | |

规则：
- 文字颜色禁止加透明度（`text-ink-faint/50` 这类）。需要更弱的层级就单独定义一档，并且本身过 4.5:1。
- 令牌名保持不变（`canvas` / `panel` / `card` / `ink-*` / `live` / `warn` / `fault` 等），只改 `tokens.css` 里的原始变量值，减少组件改动面。

### 4.2 字体

- 标题、数字、品牌：Manrope，woff2 打包进应用，只带 600 / 700 / 800。统计数字用 `tabular-nums`。
- 正文：Segoe UI Variable + Microsoft YaHei UI，不变。不用 Inter。
- 等宽：Cascadia Code，用于端口、路径、终端。
- 字号下限：正文 13px，辅助标注 12px，不再出现 11px 及以下。

### 4.3 形状与层次

- 圆角三档：卡片 16px，控件 10px，胶囊和标签 999px。大容器不用全圆角。
- 阴影三档：静态 `0 4px 14px / 0.07`，悬停 `0 8px 22px / 0.12`，浮层 `0 16px 40px / 0.16`。
- 深色主题不用阴影表现层次，靠表面逐级变亮 + 1px 描边。
- 渐变只用于品牌标识。

### 4.4 微交互

| 交互 | 表现 | 时长与曲线 |
| :--- | :--- | :--- |
| 按下 | 缩到 0.96 | 70ms |
| 松开 | 回弹 | 200ms，`cubic-bezier(.34,1.56,.64,1)` |
| 悬停 | 上浮 1px，阴影升一档 | 90ms |
| 操作失败 | 按钮轻微左右抖动并变红 | 状态切换 90ms |
| 状态点 | 运行中缓慢呼吸，异常时闪一次后常亮 | 呼吸周期 2s |
| 复制路径或端口 | 图标原地换成对勾，1.2 秒后复原 | 90ms |
| 列表选中 | 左侧指示条滑到新的那一行 | 200ms，回弹曲线 |
| 抽屉、分栏、通知条 | 滑入，遮罩淡入 | 220ms |
| 数字变化 | 新值淡入加 2px 位移，不滚动计数 | 120ms |

固定做法：
- 焦点环 3px 品牌蓝，偏移 2px。
- `prefers-reduced-motion` 开启时去掉所有位移和缩放，只保留颜色变化。
- 毛玻璃只用于标题栏、抽屉和命令面板。
- 卡片拖拽排序时，`transform` 交给 `useCardSort` 的 FLIP 动画独占，悬停抬升要让位。
- 模板的 `scale(1.02)` 悬停不采用：密集信息卡片放大会让文字发虚、挤压邻居，改为上浮 1px。

### 4.5 图标（Q17）

统一 Phosphor，去掉 `components/icons/` 自绘图标。尺寸两档：行内 16px，导航和磁贴标题 20px。默认 regular，选中态 fill。主操作一律「图标 + 文字」。

| 含义 | 图标 | 含义 | 图标 |
| :--- | :--- | :--- | :--- |
| 启动 / 运行 | `Play` | 停止 | `Stop` |
| 重启 | `ArrowClockwise` | 强制关闭 | `Prohibit` |
| 输出 | `TerminalWindow` | 诊断 | `Stethoscope` |
| 构建 | `Hammer` | 配置 | `SlidersHorizontal` |
| 概览 | `Gauge` | 打开目录 | `FolderOpen` |
| 查看产物 | `Package` | 外部打开（HBuilderX 等） | `ArrowSquareOut` |
| 移除 | `Trash` | 更多 | `DotsThree` |
| 最大化 / 还原 | `ArrowsOut` / `ArrowsIn` | 关闭 | `X` |
| 复制 | `Copy` → `Check` | 锁定字段 | `Lock` |
| 端口 | `Plug` | 工作组 | `Folders` |
| 服务（导航） | `Stack` | 总览（导航） | `Gauge` |
| 终端（导航） | `TerminalWindow` | 设置（导航） | `Gear` |
| 关于（导航） | `Info` | 动态 | `Bell` |
| 搜索 | `MagnifyingGlass` | 快捷键 | `Keyboard` |
| prod 警示 | `Warning` | 失败 | `WarningCircle` |
| 成功 | `CheckCircle` | 浅 / 深色 | `Sun` / `Moon` |
| 折叠导航 | `SidebarSimple` | 新建 | `Plus` |

框架图标（React、Vue、Spring Boot 等）和自定义图片不在此范围，继续由 `EntryGlyph` 负责。

### 4.6 保留的旧约定

- 状态色只用在描边、图标块和胶囊上，不染卡片底色。
- 禁用状态不压整块透明度，改用弱化底色 + 可见边框。
- 图标按钮必须有 `aria-label`。
- `tokens.css` 没有 `@layer`，`transition` 简写必须写全 `background-color / border-color / color / box-shadow / transform`，否则会盖掉 Tailwind 的过渡类。

## 5. 全局交互

### 5.1 反馈（Q14）

- Toast 栈在右下：成功 4 秒自动消失；失败常驻到手动关闭，带「查看输出」。
- 整组启停只发一条汇总，例如「商城项目：3 个已启动，1 个失败」。
- 应用内确认弹窗只用于：移除条目、删除工作组、强制关闭、prod 环境启动。危险按钮红色，默认焦点在「取消」。去掉 `window.confirm`。

### 5.2 键盘（Q15）

| 范围 | 按键 | 作用 |
| :--- | :--- | :--- |
| 全局 | `Ctrl+K` | 命令面板 |
| 全局 | `Ctrl+1`–`Ctrl+5` | 切换导航页 |
| 全局 | `?` | 快捷键一览 |
| 服务列表 | `↑` / `↓` | 移动选中（详情跟随） |
| 服务列表 | `Enter` | 打开详情 |
| 服务列表 | `Space` | 启停选中服务；选中工作组标题行时启停整组 |
| 详情 | `Ctrl+Tab` | 切换标签 |
| 详情 | `Esc` | 退出最大化 → 关闭详情 |

焦点在输入框、下拉框或终端内时，单键快捷键（`?`、`Space`、方向键）不生效。危险操作照样弹确认。

## 9. 风险
